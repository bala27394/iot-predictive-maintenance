STEP 7: GOVERNED WORK-ORDER AUTOMATION (COMPLETE)
──────────────────────────────────────────────────
  3 stored procedures in ORCHESTRATION schema:

  DRAFT_WORK_ORDER(incident_id)
    - Checks for duplicate active WO (same machine + failure mode)
    - Generates WO with problem description, evidence, actions, parts, repair/downtime estimates
    - Sets recommended maintenance window based on severity
    - Updates incident status to WORK_ORDER_PENDING

  APPROVE_WORK_ORDER(wo_id, approver, action)
    - Approval gate: APPROVE or REJECT
    - Logs approver and timestamp
    - Updates incident status accordingly

  RESOLVE_WORK_ORDER(wo_id, root_cause, parts, hours, findings)
    - Captures post-repair feedback
    - Records actual root cause, parts replaced, repair hours, technician findings
    - Marks incident RESOLVED
